# ศึกสติ๊กแมน 1 ต่อ 1

เกมดวลดาบคาตานะของสติ๊กแมน ควบคุมโดย AI ทั้งสองฝั่ง คุณแค่เลือกนักดาบ ทายผู้ชนะ แล้วนั่งดู

**เล่นได้ที่:** https://phanthakandt.github.io/stickman-duel/

## ระบบในเกม
- นักดาบ 13 ตัว แต่ละตัวมีท่าตั้งดาบ ค่าพลัง และท่าไม้ตายของตัวเอง เลือกตัวเดียวกันสู้กันได้ (ร่างแฝดเปลี่ยนสี)
- ท่าฟันธรรมดา 4 ระดับ จากเบาไปหนัก พร้อมเส้นแสงโค้งตามแนวฟัน
- ปัดดาบมีประกายไฟ ปัดตรงจังหวะได้ **Deflect!** ฟื้นเลือดและได้เกจพลัง
- คริติคอล 2–3 เท่า ฟื้นเลือดให้คนฟัน
- สกิลเล็กประจำดาบ ใช้มานา 1/3 หลอด และสกิลใหญ่ ใช้มานา 2/3 หลอด เชื่อมโยงกับท่าไม้ตายของดาบนั้น
- **ปลดปล่อยดาบ** ท่าไม้ตายเมื่อมานาเต็มและเลือดต่ำกว่า 40% ใช้แล้วมานาหมดหลอดและติดคูลดาวน์ 40 วินาที (นับต่อข้ามยก มีเกจใต้หลอดเลือด เกจเต็มคืออันติพร้อม)
- แข่งชนะ 2 ใน 3 ยก ไม่จำกัดเวลา ทายผู้ชนะก่อนกดเริ่ม
- ปรับพลังชีวิตได้ ×1 / ×1.5 / ×2 ที่หน้าเลือกตัวละคร (ค่าเริ่มต้น ×2 และความเร็ว 2×)
- เสียงฟัน เสียงสกิล เสียงเอฟเฟกต์ และดนตรีประกอบ สังเคราะห์สดด้วย Web Audio เปิดปิดแยกกันได้
- ค่าพลังทุกตัวปรับสมดุลจากการจำลองการแข่ง ทุกตัวชนะราว 47–52% (จำลองที่พลังชีวิต ×2)

ไฟล์เดียว `index.html` ไม่ต้อง build เปิดในเบราว์เซอร์ได้เลย
